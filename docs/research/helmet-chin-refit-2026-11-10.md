# Homepage helmet chin refit — 2026-11-10

Sir requested improving the flat/square chin relative to the reference. Compared the live reference's hero hook and helmet material source, the supplied screenshots, and the source 2023 product photo (`assets/source/max-helmet/photos-2023/front.jpg`). This is an approximate reconstruction based on product photos, not an official scan.

The homepage `scripts/helmet-scene.js` clones each artist mesh geometry on load and applies a smooth, local-space deformation only to the front lower region: the lower sides are gently drawn inward, the centre of the lower edge is moved down and forward. The same deformed positions feed the solid geometry and the merged wireframe. The original GLB and other editions' geometry are not modified. Existing vertex normals are preserved; recomputing them created visible shading seams at UV splits during the first attempt. This is a restrained adjustment, not physically reconstructed normal geometry.

`public/helmet-materials.js` adds two small, procedurally shaded triangular grille cues to the 2023 shell using object coordinates, based on the photo. They are flat shader details, not actual holes or modeled vents. It also modestly increases 2023 paint reflectivity and reduces roughness for more pronounced surface light; the 2024 tuning remains unchanged. The 2023 edition uses the shared 2023 material but retains its original geometry.

`npm run build`, `npm run check`, and `git diff --check` passed. Desktop 1470×812 full reveal and emulated mobile 390×844 full reveal were visually checked, with no recorded runtime errors, matching solid/wire scale, and no mobile page overflow. For a side-angle check, the desktop scene was temporarily set to a 0.24 rad yaw in the task browser; the page was closed afterwards. This was not a test of pointer interaction or a physical phone. The 2023 edition rendered in the browser with the shared grille cue; the status element is hidden by `.model-ready` rather than removed. Evidence is in `/private/tmp/mv33-chin-final*.png` while temporary files persist. Explicit visual acceptance remains pending.
