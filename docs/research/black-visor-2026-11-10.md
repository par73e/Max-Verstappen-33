# Homepage black visor — 2026-11-10

Sir requested the Norris reference's black visor appearance. Read live `landonorris.com` hero DOM and helmet hover hook, traced current `lando-by-OFF+BRAND.05.js` F9 glass material, and compared actual same-viewport complete helmet screens. The reference glass uses its own dark base colour and roughness/metalness/normal maps with the studio HDR environment. The MV source-geometry variant had a uniform gold reflective tint and a separately projected 2023 ORACLE banner.

In `public/helmet-materials.js`, only the homepage source-fit glass branch with a banner uses a neutral near-black tint, material roughness .06, metalness .15 and environment intensity 1.5; its banner retains separate non-metallic response and the existing projection. Iridescence is disabled if that property exists. Clearcoat values are applied conditionally only if supported by the loaded material; runtime inspection of this MeshStandardMaterial did not show clearcoat. The approach imitates the visible black studio reflection, not a direct copy of the reference base texture, which contains Norris/McLaren artwork. The normal map and original geometry remain; standalone Maubian editions and their visor colour remain unchanged.

`npm run build`, `npm run check`, and `git diff --check` passed. Inspected desktop 1470×812 frontal and temporary 0.24-rad test yaw, plus 390×844 emulated mobile full reveal. Desktop hover was real; side angle and mobile reveal were programmatically triggered for inspection and do not establish physical-phone interaction. No runtime errors, failed material program diagnostics or mobile horizontal page overflow were observed; the 2023 edition page reached ready without recorded errors.
