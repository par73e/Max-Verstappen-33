# 诺里斯首页头盔渲染调查

核查日期：2026-11-08。目的：解释实体头盔、线框、转动、质感和人物叠合的实现，并确定 MV33 的重做方向。本轮调查未修改站点运行代码。

## 结论

原站头盔使用真实三维模型，通过 Three.js / WebGL 渲染。线框从同一模型的几何生成，并同步变换，实体与线框共同使用同一透视相机。当前 MV33 封面把正面照片直接合成到屏幕坐标，而线框仍来自参考模型，失配是实现方式造成的，不是照片再挪几像素就能根治。

人物则是另一种实现：带深度位移的照片平面（2.5D），不是完整的人体三维扫描。Rive 负责 Logo、签名、按钮等界面动画，头盔主体不由 Rive 绘制。

## 各部分如何工作

| 观察到的效果 | 发布代码中的实现 | 对 MV33 的意义 |
| --- | --- | --- |
| 能看见侧面、镜片随角度反光 | `F9` 克隆 GLB，使用实际几何和透视相机；外壳与镜片各有材质 | 二维正面照片不能补出侧面、透视和表面法线 |
| 人物外围的素描头盔 | 将相同模型各部件几何合并，创建 `wireframe: true` 的着色器材质，带低透明度扫描效果 | 轮廓必须从最终头盔模型自动生成 |

| 外壳和镜片的质感 | 外壳用 `MeshStandardMaterial`、法线等材质信息，镜片有独立颜色/粗糙度/法线贴图；HDR 环境贴图参与反射 | 必须处理完整 UV 材质及镜片，不能只替换外壳的一张图 |
| 鼠标划过时局部出现 | 头盔先渲染到离屏 RenderTarget；主着色器结合流体光标纹理和遮罩混合人物与头盔 | 鼠标效果属于最终合成层，应与三维模型渲染配合 |

## 转动的一个细节

原站不是提供任意角度的 360° 拖拽查看器。默认人像微动强度为 `0.075`，头盔旋转再除以 `1.5`。完整预览动画还会把 `helmetRevealValue` 降到 0，令鼠标驱动的姿态变化趋于静止。因此完整悬停后的左右鼠标截图可能几乎一致，不能把它们当作大角度旋转演示。侧面与曲面质感由真实模型保证，小角度变化和灯光仍然有二维照片缺失的信息。

## 当前版本为什么不够

1. 最初把 Max 商品照片投影到 Norris 网格，照片与网格 UV/形状不一致；镜片又是独立部件，单替换外壳会留下原赞助标志。
2. 后来直接显示摄影抠图，改善了正面清晰度，但它是固定屏幕空间图像；线框仍是三维网格。两者无法在每个视角和视口持续吻合。
3. 用照片自带的固定反光代替三维材质，不能得到随观察角度改变的镜片与外壳反射。
4. 缩放和移位只能修复某一帧的外观，不能使两个不同几何来源变成相同模型。

## 重做方向与验收

优先寻找有明确使用条件、可导出 GLB 的 Max / Schuberth 头盔模型，必须含实际侧面与可用 UV；确认 2023 常规款和 2024 赞德沃特款的造型是否可共用模型，再决定使用一套模型切换涂装还是两套模型。只有正面渲染图或只有无材质 STL 时，不应宣称已满足原站效果。

接入后，实体与线框由同一模型派生，统一位置、缩放、相机和旋转。为两款制作/整理匹配该模型 UV 的外壳贴图、镜片材质与必要的法线/粗糙度信息，然后复用现有流体合成与悬停时间轴；保留人物肩膀和上半身。

验收需要同时覆盖默认轮廓、移动时局部揭示、完整悬停、退出悬停以及桌面/手机比例。不能只检查正面静帧，也不能只以没有脚本错误作为视觉通过。

模型的匹配程度、两款涂装的可用素材及再分发条件仍待核实。此前提出的两个头盔页面、深浅标签图标和橙色 MV 元素仍在待办；本轮没有把它们标记为已实现。

## 2026-11-09 implementation follow-up

The user supplied Maubian's CC BY 4.0 GLB from Sketchfab. A separate background Blender process normalized the mesh into the original renderer's coordinate system. The hero now renders a GLB again, and its wireframe is generated from that exact GLB. The photographic screen-space compositor replacement was removed.

The artist's supplied livery is a later interpretation (including Gate.io), not the requested 2023 design. New edition color maps are reconstructed from the retained 2023 product photographs and the official 2024 Orange Tribute gallery. Blender baking uses unique UV islands, calibrated source view directions and a strong frontal preference for the 2023 design. View blending and side seams remain approximate. This is an approximate reconstruction; it does not recover a manufacturer-authored UV layout or claim perfect livery fidelity. The source model and original photographs are preserved.

Implementation: `scripts/prepare_helmet.py`, `scripts/bake_helmet_editions.py`, `scripts/export_helmet_editions.py`, `scripts/helmet-scene.js`; two routes are generated by `scripts/build_helmet_pages.py`. Page controls expose front/left/right/back, pointer orbit and matching wireframe. The homepage retains the original fluid reveal and shared camera pipeline.
