# Homepage reference helmet proportions — 2026-11-10

Sir explicitly asked to reproduce the Norris helmet proportions exactly. Checked live `landonorris.com` hero DOM (`[data-gl="head"]`, `[data-gl-helmet="hover"]`) and its current `lando-by-OFF+BRAND.05.js` F9. The source helmet uses its own GLB, scale [6.9, 6.9, 7.1], responsive camera and shared head/helmet state. One task browser compared the live reference, the then-default Maubian reconstruction and the pre-existing `/?helmet=source` alternative at the same desktop viewport.

The homepage now defaults to the retained OFF+BRAND reference-derived geometry (`source-fit-season-2023.glb`) and the source scale [6.9, 6.9, 7.1]. The home uses the same existing camera/rotation hooks; solid and wireframe use that geometry. This is reference helmet geometry, not Maubian's helmet or a Max/Schuberth scan. `/?helmet=artist` selects the previous Maubian comparison; standalone edition routes still use the Maubian mesh. Source-related `userData` is retained, so artist-only chin and visor deformations do not run on the source geometry.

The existing source-fit artwork had a severely misprojected ORACLE band and photographic red visor reflection projected onto the chin. In `public/helmet-materials.js`, the source glass now uses a physical reflective visor and samples the actual 2250×3000 front product photograph for a projected ORACLE band. The source shell shader neutralizes the misprojected centre strip and adds approximate grille shading. These are reconstructed material cues, not manufacturer UV artwork or physically modeled grille holes; Max's actual helmet shape and vent layout do not match the Norris reference geometry. Existing photo-derived seams and fading remain, especially at oblique angles. `public/max/helmet-2023-front-hq.jpg` is an unmodified copy of `assets/source/max-helmet/photos-2023/front.jpg`; provenance is listed in `assets-manifest.json`. Home footer/About and README distinguish OFF+BRAND home geometry from Maubian standalone models.
